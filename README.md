# Grade Classifier

Project Java Maven mẫu có vòng lặp và rẽ nhánh, kèm 2 nhóm test JUnit:

- Statement coverage
- Path coverage

## Chạy kiểm thử

```bash
mvn test
```

## Gợi ý nộp bài

1. Commit code chương trình.
2. Tạo 2 issue trên GitHub.
3. Viết test cho từng issue, commit tương ứng.
4. Push toàn bộ lên repository GitHub của bạn.
